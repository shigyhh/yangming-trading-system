# 小程序体验版真机验收清单

目标：体验版每次上传后，用同一套清单确认“能打开、能训练、能保存、能同步、合规可见”。

- 微信版本：
- 测试账号：
- 网络：Wi-Fi / 4G / 5G / 弱网

## 启动与更新

- [ ] 首次打开不白屏。
- [ ] 冷启动进入首页。
- [ ] 清缓存后能重新进入。
- [ ] 有新版本时，弹出“新版本已就绪”提示。
- [ ] 点击“立即重启”后能应用新版本。

## 首页

- [ ] 第一眼能看到“今日心证”。
- [ ] 主行动入口清晰。
- [ ] 合规说明可见。
- [ ] 没有荐股、喊单、预测行情、收益承诺。

## 真实复盘

- [ ] 能从首页进入真实复盘。
- [ ] 能填写买卖原因、当时念头、纪律执行、下一次动作。
- [ ] 保存后本地记录存在。
- [ ] 同步失败时不影响本地保存。
- [ ] 同步成功后有本地同步状态。
- [ ] 复盘内容没有生成买卖建议。

## K线观心

- [ ] 能进入 K线观心。
- [ ] A股训练入口可用。
- [ ] 请求使用 `https://xxjyxt.com/api/v1/kline-history/slice`。
- [ ] server 返回 candles 时使用 server slice。
- [ ] server 不可用时显示本地练习样本，不误导为正式行情。
- [ ] 完成训练后保存本地记录。
- [ ] 完成训练后触发 server 同步。
- [ ] 同步失败时记录 pending / failed，不阻断训练完成。
- [ ] 训练记录包含 `klineSource` / `serverSliceStatus`。

## 活镜成长

- [ ] 真实复盘后活镜有变化。
- [ ] K线训练后活镜有变化。
- [ ] 最近复盘能展示。
- [ ] 高频心贼或主镜统计不为空时展示正常。

## 我的与合规

- [ ] 我的页面可打开。
- [ ] 合规说明可打开。
- [ ] 文案明确：本系统用于交易心理觉察与训练，不提供投资建议，不预测行情，不构成操作依据。
- [ ] 不展示手机号、token、验证码等敏感信息。

## 服务器接口

- [ ] `https://xxjyxt.com/api/v1/auth/demo-login` 可用。
- [ ] `https://xxjyxt.com/api/v1/data-binding/...` 可用。
- [ ] `https://xxjyxt.com/api/v1/kline-history/slice` 可用。
- [ ] 网络失败时页面有可理解提示。
